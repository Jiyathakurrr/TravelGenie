# Team Roles & Responsibilities

The TravelGenie Capstone project is developed by a dedicated team of three members. This document outlines the specific roles and responsibilities for each member to ensure clear accountability.

---

## 🧑‍💼 Prachi
**Role:** Product Manager & Research Coordinator

**Responsibilities:**
- **Requirement Gathering:** Defining MVP scope, user stories, and acceptance criteria.
- **Market Research:** Analyzing competitors to ensure TravelGenie provides a unique value proposition.
- **Sprint Planning:** Managing the agile process, setting sprint goals, and tracking progress.
- **Documentation:** Maintaining non-technical project documentation and presentation materials.
- **Product Decisions:** Acting as the tie-breaker for feature scope and UX decisions.

---

## 👩‍💻 Jiya
**Role:** Developer & Tester

**Responsibilities:**
- **Frontend Development:** Building the Next.js UI using Tailwind CSS and React.
- **Backend Development:** Implementing the Express.js server logic and API routes.
- **Chatbot Development:** Integrating OpenAI and building the intent-parsing conversational interface.
- **API Integration:** Connecting frontend to backend, and backend to third-party services.
- **Database Integration:** Writing queries and connecting to Supabase.
- **Quality Assurance:** Writing Unit and Integration tests. Bug tracking.
- **GitHub Maintenance:** Maintaining repository health, reviewing PRs for code quality.

---

## 👩‍🔧 Hitanshi
**Role:** System Designer & Deployer

**Responsibilities:**
- **System Architecture:** Designing the High-Level architecture and system flow.
- **Database Design:** Creating the ER diagrams and implementing the Supabase PostgreSQL schema.
- **Deployment:** Managing Vercel and Render deployments.
- **DevOps:** Managing environment variables, secrets, and infrastructure.
- **Hosting:** Ensuring uptime and monitoring resource usage.
- **CI/CD:** Setting up GitHub Actions for automated testing and deployment.
