# Contributing to TravelGenie

First off, thank you for considering contributing to TravelGenie. It's people like you that make TravelGenie such a great tool for travel planning.

## Development Workflow

1. **Branching Strategy:**
   - `main`: Production-ready code.
   - `develop`: Integration branch for upcoming releases.
   - Feature branches: `feature/your-feature-name`
   - Bugfix branches: `bugfix/issue-description`

2. **Making Changes:**
   - Ensure your code follows the guidelines in [CODING_STANDARDS.md](CODING_STANDARDS.md) and [STYLE_GUIDE.md](STYLE_GUIDE.md).
   - Write or update tests as appropriate.
   - Run the test suite before submitting a PR.

3. **Submitting a Pull Request:**
   - Push your branch to GitHub.
   - Open a PR against the `develop` branch.
   - Ensure you use the provided Pull Request template and fill out all necessary sections.
   - Wait for a code review from one of the core team members (Prachi, Jiya, or Hitanshi).

## Issue Tracking

- **Bugs:** Use the Bug Report template.
- **Features:** Use the Feature Request template.
- Please check existing issues before creating a new one to avoid duplicates.
