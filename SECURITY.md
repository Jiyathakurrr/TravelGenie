# Security Policy

## Supported Versions

Currently, TravelGenie is in the MVP phase. Security updates will only be provided for the latest development build on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of TravelGenie seriously. If you discover a security vulnerability within TravelGenie, please send an e-mail to the core team rather than creating a public issue.

1. Email us at `security@travelgenie-example.com` (Placeholder email).
2. Include a detailed description of the vulnerability and steps to reproduce.
3. We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.

If the vulnerability is accepted, a patch will be deployed as soon as possible and the reporter will be credited (if desired).
