# Project Roadmap

This document outlines the strategic high-level roadmap for TravelGenie from inception to final Capstone defense.

## Milestone Plan

### Milestone 1: Project Foundation (Weeks 1-2)
- [x] Finalize team roles and responsibilities.
- [x] Gather requirements and perform market research.
- [x] Establish GitHub repository, CI/CD templates, and documentation.
- [ ] Define database schemas and API specifications.

### Milestone 2: MVP Development - Core Modules (Weeks 3-6)
- [ ] Implement Trip Planning Engine (destination, dates, budget).
- [ ] Develop the Mock Budget Comparison Module (JSON files).
- [ ] Setup Supabase PostgreSQL and authentication.
- [ ] Build base Next.js frontend structure.

### Milestone 3: AI & Chatbot Integration (Weeks 7-9)
- [ ] Integrate OpenAI API for itinerary generation.
- [ ] Build Chatbot conversational interface.
- [ ] Implement direct database itinerary patching via chatbot intents.
- [ ] Implement itinerary versioning.

### Milestone 4: Booking & Error Handling (Weeks 10-11)
- [ ] Build Booking Module UI/UX.
- [ ] Implement inline error handling for price changes and unavailability.
- [ ] Connect booking flows to mocked backend responses.

### Milestone 5: Testing, QA, & Polish (Weeks 12-14)
- [ ] Execute comprehensive unit and integration tests.
- [ ] Conduct manual QA across multiple devices.
- [ ] Refine UI/UX, animations, and transitions.
- [ ] Finalize deployment pipelines on Vercel and Render.

### Milestone 6: Final Presentation (Week 15)
- [ ] Freeze code (`main` branch).
- [ ] Prepare Capstone presentation and demonstration script.
- [ ] Submit final documentation to reviewers.

## Future Enhancements (Post-MVP)
- **Live APIs**: Replace mock JSON data with live Amadeus or Skyscanner APIs.
- **Social Features**: Allow multiple users to collaborate on a single itinerary.
- **Mobile Application**: Port the web app to a React Native mobile application.
